# Student Performance Analytics Engine

A Python-based student performance analysis project built using NumPy and Pandas in Google Colab.

## Features
- 500 students and 6 subjects
- Statistical analysis
- Z-score outlier detection
- Student ranking
- Total marks calculation
- CSV report generation

## Tech Stack
- Python
- NumPy
- Pandas
- Google Colab

## Dataset
A simulated dataset containing 500 student records across six subjects.

## Execution
Open the notebook in Google Colab and run all cells sequentially.

## Output
`student_performance.csv`

## Purpose
To demonstrate NumPy arrays, broadcasting, statistical operations, sorting, and data analysis.
